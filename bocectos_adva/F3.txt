Descripción de la Interfaz del Módulo de Simulacro
La interfaz está diseñada para un flujo de trabajo administrativo que centraliza la creación de eventos, la navegación por resultados históricos y el proceso riguroso de carga de archivos Excel.

1. Panel Izquierdo: Navegación y Trazabilidad
Este panel se divide en dos secciones principales y actúa como el centro de control para seleccionar el evento de simulacro que se desea gestionar o visualizar.

A. Sección "SIMULACROS ACTUALES"
Propósito: Muestra las Modalidades Académicas que existen en el sistema (grupos de estudiantes).

Elementos:

Encabezado: "SIMULACROS ACTUALES" con un botón (+) que sugiere la funcionalidad de Creación de un nuevo Evento de Simulacro (la nueva entidad que contendrá los resultados), la subida de cada resultado

la creación de un nuevo simulacro tiene que ser un modal en el que se tenga que llenar los siguiente dato:
-nombre del evento simulacro que contendrá cada resultado.
-El elegir el numero de preguntas, 20 ,40, 80 , 100 preguntas por defecto que solo calificara este evento siimulacro
-añadir las modalidades existentes a las que pertenecerá este evento simulacro, Valores predefinidos para elegir.
-añadir temática de rango de preguntas que gestionara 

B. Sección "RESULTADOS DE: [Modalidad Seleccionada]"
Propósito: Muestra el historial de archivos de resultados que ya han sido cargados y procesados dentro de una Modalidad específica.

Elementos:

Encabezado: "RESULTADOS DE : simulacro PRE-U" (o el nombre que se le dio al simulacro), indicando el filtro actual. este tiene que estar en un panel izquierdo debajo del panel de creación de simulacros.

Listado: Muestra los nombres de los archivos procesados (Ej. "Resultados_simulacro_12.xlxx", "Resultados_simulacro_11.xlxx", etc.), permitiendo al usuario seleccionar uno para ver sus métricas finales.

2. Panel Derecho: Carga Interactiva y Validación
Este panel es el área de trabajo donde el administrador realiza la subida de un nuevo archivo de resultados dependiendo del simulacro seleccionado, implementando un proceso de validación en tres fases antes de la subida final de un nuevo archivo.

A. Título y Contexto
Título Principal: Indica el contexto del proceso, como "Subir nuevos resultados de simulacros PRE-U(la modalidad seleccionadad)".

Nombre del Archivo: poner el nombre asignado al nuevo resultado del Simulacro que se está gestionando (Ej. "resultados_simulacro_13").

B. Área de Carga y Clave de Respuestas
Selector de Archivo: Un área denominada "Subir nuevos resultados" que incluye un ícono de Excel, indicando que se debe seleccionar el archivo de la computadora.

Botón "Llenar respuestas": Este botón es crucial. Dispara una funcionalidad (probablemente un modal) que permite al administrador ingresar o confirmar la clave de respuestas correcta para este evento específico de simulacro.

C. Análisis y Validación Previa (Punto Crítico), este estara debajo del la subida del archivoa evaluar, que caragara previamente la primera columnas de "codigo de estudiantes", esto para verificar que cada pasticipante , si esta en la base de datos
Encabezado: "Análisis del archivo".

Tabla de Validación: Muestra una lista de los códigos de estudiante extraídos de la primera columna del archivo Excel.

Funcionalidad Implícita: Esta lista es el resultado de la Validación de Códigos realizada por el sistema contra la base de datos de estudiantes.

Feedback Visual: El sistema utiliza colores para indicar el estado:

Encontrado (Negro/Verde Implícito): El código existe y pertenece a la Modalidad(es) seleccionada(s). (Ej. 76412121).

No Encontrado (Rojo): El código no existe en el sistema o no está asociado a las modalidades del evento. (Ej. 84512356).
